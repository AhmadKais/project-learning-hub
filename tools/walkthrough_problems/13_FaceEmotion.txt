app/vision/preprocessor.py::FacePreprocessor.to_model_input
Turn a face crop into what the network expects: grey, resized to 48x48, equalised, scaled to 0-1, normalised with the training mean and std, shaped (1, 1, 48, 48). The steps must match the evaluation transform exactly.

app/vision/preprocessor.py::FacePreprocessor.process

app/ml/dataset.py::build_train_transform
The training transforms: grey, equalise, random flip, small rotation and crop, to tensor, normalise, and random erasing. The randomness makes the model robust; it is used for training only.

app/ml/dataset.py::build_eval_transform
The evaluation transforms: grey, resize to 48x48, equalise, to tensor, normalise - no randomness, and the same steps as the camera path.

app/ml/network.py::ResidualBlock.__init__
Create the two 3x3 convolutions with batch norm and ReLU, and the shortcut: the identity when the shape stays the same, otherwise a 1x1 convolution with batch norm.

app/ml/network.py::ResidualBlock.forward
conv-bn-relu, conv-bn, add the shortcut, then ReLU. Adding the shortcut before the last ReLU is what lets the gradient flow back through deep networks.

app/ml/network.py::EmotionNet.__init__
Build the network: a stem (1 to 64 channels), four residual blocks (64, 128, 256, 512 channels, halving the size from block 2 on), and a head (average pool, dropout, linear to 7). About 4.9 million parameters.

app/ml/network.py::EmotionNet.forward
Pass the batch through stem, the four blocks and the head. Return raw logits - no softmax here, CrossEntropyLoss applies it.

app/ml/dataset.py::compute_class_weights
Give rare emotions a bigger weight in the loss: total / (7 x count) for each class, scaled so the average weight is 1. Return a tensor on the training device.

app/ml/trainer.py::ModelTrainer.__init__
Create the loss (with the class weights and label smoothing), the AdamW optimiser, a learning-rate schedule (warm-up then cosine) and the gradient scaler for mixed precision on a GPU.

app/ml/trainer.py::ModelTrainer.train_one_epoch
One pass over the training data: move each batch to the device, compute the loss, back-propagate and step the optimiser. Return the average loss and accuracy.

app/ml/trainer.py::ModelTrainer.validate
The same loop over the validation data, in eval mode and without gradients or optimiser steps.

app/ml/trainer.py::ModelTrainer.fit
Train for the given epochs: train, validate, step the schedule and print a line per epoch. Save the best model whenever validation accuracy improves and the last model every epoch, and stop early after 8 epochs without improvement.

app/ml/trainer.py::ModelTrainer.save_checkpoint
Save the weights, the optimiser state, the epoch, the validation accuracy and the pre-processing constants together, so a model file can never be used with the wrong normalisation.

app/ml/trainer.py::ModelTrainer.plot_history
