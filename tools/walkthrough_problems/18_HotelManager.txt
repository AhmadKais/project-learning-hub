hotelmanager/models/date_range.py::DateRange.__post_init__
Refuse impossible stays the moment a DateRange is created: check-out must be after check-in, and a stay may not be longer than config.MAX_NIGHTS. Because the class is frozen, an invalid stay can then never exist anywhere in the program.

hotelmanager/models/date_range.py::DateRange.nights
Return how many nights the guest sleeps: check-out minus check-in, in days. 3 March to 7 March is 4 nights - there is no "+1" because the check-out day is not a night.

hotelmanager/models/date_range.py::DateRange.overlaps
Return True when two stays share at least one night. Two half-open ranges [a, b) and [c, d) overlap exactly when a < d and c < b. A guest leaving on the 7th and another arriving on the 7th do NOT overlap - the room is re-let the same day.

hotelmanager/models/date_range.py::DateRange.contains
Return True when `day` is one of the nights of the stay: check-in counts, check-out does not.

hotelmanager/models/date_range.py::DateRange.nights_list
Give the nights of the stay one by one, from check-in up to the day before check-out. [3 March, 7 March) gives 3, 4, 5, 6 March - one price per night is built from this list.

hotelmanager/models/entities.py::Room.fits
Return True when the room is active and has at least `guests` beds. A double room (capacity 2) fits exactly 2 guests.

hotelmanager/models/entities.py::Booking.occupies
Return True when this booking holds the room on `day`: the booking still blocks the room (confirmed or checked in) and the day is one of its nights. A cancelled booking frees the room automatically.

hotelmanager/booking/availability.py::is_room_free
Return True when no booking blocks this room during `stay`. Skip bookings of other rooms, cancelled or checked-out bookings, and the booking being edited (`ignore_booking_id`); any other booking that overlaps makes the room busy.

hotelmanager/booking/availability.py::free_rooms
Return every room that fits the guests, has the requested type (if one is given) and is free for the whole stay.

hotelmanager/booking/allocation.py::FirstFreeStrategy.choose
Pick the free room with the lowest number, or None when the list is empty. Compare the numbers as ints, so room 9 comes before room 10.

hotelmanager/booking/allocation.py::BestFitStrategy.choose
Pick the smallest room that still fits (then the cheaper, then the lower number), or None. Giving a couple the family room would leave the next family without a room.

hotelmanager/booking/allocation.py::PreferenceStrategy.score
Score one room against the guest's wishes: +3 for the wanted view, +2 for the wanted floor, +1 for the wanted type, and -1 for every unused bed. Use preferences.get(...) because a wish may be missing.

hotelmanager/booking/allocation.py::PreferenceStrategy.choose
Pick the room with the highest score; on a tie take the lower room number. Return None when there are no rooms.

hotelmanager/booking/allocation.py::create
Turn a strategy name from the config into a strategy object ("first_free", "best_fit" or "preference"). An unknown name raises ValueError that lists the valid names.

hotelmanager/pricing/rules.py::Season.contains

hotelmanager/pricing/rules.py::PricingContext.season_for

hotelmanager/pricing/rules.py::BaseRateRule.lines
Price the room night by night: the room rate times the season multiplier of that night. Group nights with the same price into one invoice line, for example "4 night(s) x double @ 450.00".

hotelmanager/pricing/rules.py::WeekendSurchargeRule.lines
Add one line for the Friday and Saturday nights: each costs an extra 20% of that night's price (season included). No weekend nights - no line.

hotelmanager/pricing/rules.py::LongStayDiscountRule.lines
From 7 nights on, take 10% off the room part (the lines added so far). The discount is a line with a negative price, so the total is still just the sum of the lines.

hotelmanager/pricing/rules.py::ExtrasRule.lines
Add one line per extra the guest chose: breakfast is charged per guest per night, the other extras per night. Unknown extras are ignored.

hotelmanager/pricing/rules.py::VatRule.lines
Add one "VAT 18%" line on everything above. It must be the last rule.

hotelmanager/pricing/engine.py::PricingEngine.quote
Run the rules in order, giving each one the lines added so far, and return a Quote with all the lines.

hotelmanager/models/entities.py::Quote.subtotal

hotelmanager/models/entities.py::Quote.total
Add up every line, VAT and discounts included, rounded to 2 decimals - what the guest pays.
